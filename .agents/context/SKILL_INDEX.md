# AI Skill Index

When tasked with specific domains, refer to these active skills:

- **Behavior & Execution**: Always follow `karpathy-guidelines` for simplicity, surgical changes, and goal-driven execution.
- **Refactoring & Code Quality**: Invoke `code-reviewer` and `javascript-pro`.
- **Database Issues**: Invoke `postgres-pro` or `database-optimizer` for slow queries and schema design.
- **System Design**: Invoke `architecture-designer` or `microservices-architect` for new modules.
- **Debugging**: Invoke `debugging-wizard` for complex trace analysis and error hunting.
- **Documentation**: Call `code-documenter` for API specs and `spec-miner` for undocumented legacy code.
- **Testing & Security**: Use `test-master` for writing tests and `security-reviewer` for audits.
- **Critical Review**: Ask `the-fool` to red-team your proposals and find edge cases.
